# 🌾 แดชบอร์ดทะเบียนเกษตรกร อ.ห้วยราช จ.บุรีรัมย์ (Farmer Registration Dashboard)

แดชบอร์ดวิเคราะห์ข้อมูลทะเบียนเกษตรกรจำลอง อำเภอห้วยราช จังหวัดบุรีรัมย์ รวม 8,926 แปลงเพาะปลูก ครอบคลุม 3 ปีงบประมาณ (2565 - 2567)  
ออกแบบภายใต้แนวคิด **Minimalist & High Contrast** และจำกัด **ระบบสีไม่เกิน 5 สี (The Strict 5-Color System)** เพื่อความคมชัด อ่านง่าย สบายตา และประมวลผลรวดเร็ว

---

## 🎨 ระบบ 5 สีตัดกัน (The 5-Color System)

| รหัสสี | สี | บทบาทในแดชบอร์ด |
| :--- | :--- | :--- |
| **`#FFFFFF`** | ⚪ ขาว | พื้นหลังการ์ด / ตัวอักษรบนแถบมืด / ผืนผ้าใบแสดงข้อมูล |
| **`#0B132B`** | ⚫ ดำเนวี่ | ตัวหนังสือหลัก / ขอบเส้นโครงสร้าง (Solid 2-3px) / หัวตาราง |
| **`#059669`** | 🟢 เขียวมรกต | ข้าวเจ้า, ข้าวเหนียว / สถานะผ่านการประชาคม / ตัวเลข KPI เนื้อที่ไร่ |
| **`#2563EB`** | 🔵 น้ำเงินสด | มันสำปะหลัง, ยางพารา / ระบบ FARMBOOK / สถิติดิจิทัล |
| **`#D97706`** | 🟡 อำพันทอง | อ้อยโรงงาน, พืชอื่นๆ / สถานะรอประชาคม / ไฮไลต์แจ้งเตือน |

## 🚀 ฟีเจอร์หลัก (Features)

1. **4 KPI Cards สรุปข้อมูลด่วน:**
   - จำนวนแปลงเพาะปลูกทั้งหมด
   - เนื้อที่เพาะปลูกรวม (ไร่) พร้อมค่าเฉลี่ยไร่ต่อแปลง
   - อัตราการผ่านการประชาคม (%)
   - สัดส่วนการขึ้นทะเบียนผ่านแอปพลิเคชัน FARMBOOK (%)

2. **ตัวกรองข้อมูลแบบเรียลไทม์ (Interactive Filters):**
   - กรองปีงบประมาณ: 2565 / 2566 / 2567 / ทั้งหมด
   - กรองรายตำบล: ทั้ง 7 ตำบลใน อ.ห้วยราช (โคกเหล็ก, สามแวง, ห้วยราชา, บ้านตะโก, สนวน, ตาเสา, เมืองโพธิ์)
   - กรองชนิดพืช, สถานะการประชาคม, และช่องทางการบันทึก (ทบก. vs FARMBOOK)

3. **4 ชาร์ตวิเคราะห์ข้อมูลเชิงลึก:**
   - กราฟแท่งแนวโน้มเนื้อที่เพาะปลูกรวมรายปี (2565–2567)
   - กราฟโดนัทสัดส่วน 5 พืชเศรษฐกิจหลัก
   - กราฟแท่งแนวนอนจัดอันดับเนื้อที่เพาะปลูกตามตำบล
   - กราฟแท่งเปรียบเทียบช่องทาง ทบก. vs FARMBOOK และสถานะประชาคม

4. **🗺️ แผนที่พิกัดแปลงจริง (Interactive GIS Map):**
   - แปลงพิกัด UTM Zone 48 (X, Y) สู่ GPS (Lat/Lon) จริง ปักหมุดแปลงเกษตรกรใน อ.ห้วยราช
   - แยกสีหมุดตามชนิดพืช คลิกดูข้อมูลแปลงรายบุคคลได้ทันที

5. **📋 ตารางข้อมูลและการส่งออก (Data Explorer & Export):**
   - ค้นหาชื่อเกษตรกรหรือชนิดพืชแบบพิมพ์แล้วเจอทันที (Live Search)
   - ระบบแบ่งหน้า (Pagination)
   - ปุ่มดาวน์โหลด **CSV (UTF-8 with BOM)** เปิดภาษาไทยใน Microsoft Excel ได้ถูกต้อง 100%

## 💻 วิธีการเปิดใช้งาน (Getting Started)

### ทางเลือกที่ 1: เปิดใช้งานแบบ Standalone (ไม่ต้องติดตั้งเซิร์ฟเวอร์)
- ดับเบิ้ลคลิกไฟล์ `index.html` เพื่อเปิดใช้งานบนเว็บเบราว์เซอร์ได้ทันที

### ทางเลือกที่ 2: รันผ่าน Local Web Server
```bash
# รันด้วย Python
python -m http.server 8000
```
เปิดเบราว์เซอร์ไปที่: `http://localhost:8000`
